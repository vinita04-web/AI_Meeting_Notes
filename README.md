# AI Meeting Notes Generator

This project converts meeting audio into text and automatically extracts important meeting notes.

Technologies Used:
- Python
- Streamlit
- Whisper AI
- FFmpeg

How to Run:
1. Install Python

2. Install FFmpeg

3. Install dependencies:
   pip install -r requirements.txt

4. Run:
   streamlit run app.py

   This project requires FFmpeg to be installed on the system.
